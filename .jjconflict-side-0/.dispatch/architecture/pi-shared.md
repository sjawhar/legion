The private workspace package both Oh My Pi plugins bundle (`@legion/pi-shared`): the versioned in-process interface the Envoy plugin publishes and the Legion plugin reads, and the modules both entries inline — the role-claim bridge, the injected-user-turn record, the subagent check, the host types — with the real-binary test harness and the shared skills-guard and cross-import rules.
