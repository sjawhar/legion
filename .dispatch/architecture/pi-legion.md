The Oh My Pi plugin a Legion pane loads beside the Envoy plugin (`@sjawhar/pi-legion`): the Legion lifecycle tool, the daemon handshake and credential grants for root architects, phase workers and the controller, the task agents Legion's prompts dispatch, and the eight Legion skills. It needs the Envoy plugin's interface from `pi-shared` at the version it speaks, and refuses to run a Legion session without it.
