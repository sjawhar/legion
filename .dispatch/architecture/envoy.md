The Go-based event transport: webhook ingress, NATS routing and delivery, the native Dispatch server, and the MCP bridge. Dispatch's database is PostgreSQL 18 with pgvector: `envoy-infra`'s `gcp:Dispatch` defaults a new instance to `POSTGRES_18`, and `internal/testpg`, `scripts/dev-postgres.sh` and `deploy/compose/dispatch.acceptance.compose.yml` pin one pgvector-on-18 image by digest. Dispatch packages no child component claims sit here directly, among them the embedding queue (`internal/dispatch/embedqueue`) that keeps meaning search's vectors current, an issue's from its title and its spec. Its NATS hub comes in two forms, both deployed by `envoy-infra` (`packages/envoy/infra`, a Go module of its own that builds a Pulumi plugin and the `envoy-infra` command, and compiles only `daemonpermissions`, `internal/bus` and `internal/contracts` from Envoy): `gcp:NatsHub`, one nats-server on a Google Cloud VM that joins the tailnet, and `gcp:ClusteredNatsHub`, three nats-server pods on a GKE cluster whose optional Tailscale Service hosts also run the session listener. Both render their NATS users through the one function in `packages/envoy/infra/gcp/natshub.go`, from the permission sets `packages/envoy/infra/core` builds.

The secrets broker sits here too (`cmd/broker`, `internal/broker`), and with it this repository's one Go client of its RFC 8693 token exchange: `internal/brokerclient`, re-exported as `packages/envoy/brokerclient` so a module outside this one can import it past Go's internal-package rule, which is how `packages/daemon`'s `legion controller start` mints the controller's own Dispatch token. A machine trades the Google identity token `internal/googleidentity` reads from its metadata server for a DPoP-bound access token and the launcher credential the same trade mints, under which it enrols its session; a person signs in on that machine with `agent-secrets login`, whose device grant gives their own identity token, traded with the machine's as the actor token and recorded as a `person_signins` row keyed by the box key. The Go client and the TypeScript one (`packages/broker-client`) are held to one wire by the corpus at `internal/brokerclient/testdata/wire.json`, which both suites replay. `scripts/dev-stack.sh` boots the stand-in issuer (`cmd/dev-oidc-issuer`), the broker, NATS, the listener and Dispatch together, so the whole path can be driven on one machine with no Google and no cluster.
