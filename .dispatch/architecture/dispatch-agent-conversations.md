Built (LEGION-232): the live view at `/agents/<session>/live`, `packages/dispatch/web/src/features/agent-view/` in the web app and `@legion/pi-shared/agent-stream` on the session's side. Two decisions settled it: build on **assistant-ui** rather than write a client, and **stream live without storing** — a session's content passes through the Dispatch server to an open page and is never written to its database, leaving the session's own transcript on its host as the record. A session publishes its events to the Envoy listener, which relays them to the Dispatch server, which serves them to the web app; talking back reuses the existing delivery modes. An Oh My Pi session publishes from the `pi-envoy` extension and a Claude Code session from the claude-envoy plugin's own Claude Code mod (INFRA-1026), so both show each prompt, the assistant's text as it is written, its thinking where the host keeps it, and each tool call with its arguments and its result. The targeted exchanges a person sent a session (`btw`, `aside`, `steer`) and its replies are stored as before, and the thread shows them beside the streamed turns. This component has no paths of its own: its code lives in the Dispatch web and plugin components.
