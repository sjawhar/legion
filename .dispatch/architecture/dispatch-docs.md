The live document surface: the collaborative websocket room, two-phase settlement that mints block ids before it persists and compares what it rendered, the agent edit operations (`replace`, `delete`, `insert`, `retype`, `move`, `delete_row`, `delete_column`), block tokens and preconditions, and ask and comment anchor refresh.

A transaction a handler joins (`Docs.Join`) or a settlement opens has a read phase and a write phase. The read phase takes the document owner's advisory lock (`lockArtifactOwner`), the in-memory writer slot, the copy lock where one is needed and the document's advisory lock, in that order - none of them a row lock, so none gives the transaction a transaction id - reads, and does every operation's work: forks and renders, `refreshAnchors`' walk, version capture, reference extraction, the approval carry. Every write an operation makes goes through `write`, which queues it on the transaction's ledger (`WriteStep`; a handler queues its own writes in the same queue with `Ledger.Queue`), and a read that would have seen the transaction's own write is answered from the ledger: pending appends count toward the document head (`withOwnAppends`), pending anchors toward a refresh's walk (`RegisterPendingAnchor`), a pending version's number, time and markdown (`NextVersion`, `Now`, `PendingVersionMarkdown`). `Ledger.Commit` runs the queue in order, so statements and events keep the order the transaction made them in, then records settlement credit, commits and publishes to the rooms; a step that fails stops the queue, the transaction rolls back, no room sees its changes, and `Commit` returns that step's error unchanged. `Discard` drops the queue. Settlement, the block-index backfill and decided-wording restoration queue their writes on a ledger of their own (`queueWrites`) and run it right before they commit. The anchor-refresh writes, an update and a `*.anchor_refreshed` append per changed anchor, run in the write phase one round trip each, so they are transaction-id time; batching them is INFRA-605's.
