The live document surface: the collaborative websocket room, where ygo returns a read-write peer's awareness update to its sender, and a read-only peer an empty awareness response, so the Hocuspocus provider stays connected without Dispatch writing frames; settlement; the agent edit operations (`replace`, `delete`, `insert`, `retype`, `move`, `delete_row`, `delete_column`) and the ask blocks an edit adds, which the API checks for related items, block tokens and preconditions, and ask and comment anchor refresh. Settlement runs in passes and renders nothing while it holds the document's owner row: a pass renders the live tree before its transaction, a block-id stamp commits alone, ask repairs are planned with no lock and committed in a transaction of their own, and the next pass writes the version from what it rendered. At most four settlements run at once, however they start, each on the settlements pool, and a timer's settlement has 60 seconds; one that runs out of time or connections rolls back and is left to the resumption, which fails no room. Every live write takes its documents' writer gates first (`AcquireDocumentWriter`): one writer per document at a time, queued in memory holding no connection or admission unit, 32 at most (`ErrPreconditionBusy`, answered `429 EDIT_QUEUE_FULL`), refused to a caller holding a connection; a live write whose context lacks its document's gate is refused. Its background loops (settlement resumption, task progress, reference excerpts, block index, edit notices) read through the background pool.
