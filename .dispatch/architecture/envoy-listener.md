Ingests GitHub, Slack and Ghost Wispr webhooks, publishes ordinary notifications through JetStream and role lanes through core NATS, resolves live sessions and delivers by `prompt_async`; tracks PR check settlement. The small packages that instrument that path belong to it rather than to components of their own: service-account token verification (`oidc`), the signature and duplicate-delivery guards (`verify`, `dedupe`), `metrics`, `id`, `logging`, listener bootstrap (`config`), the `natstail` diagnostic tail, and the listener's own harnesses (`integration`, `smoke`, `testnats`). `internal/dispatch/config` sits under the Dispatch tree but belongs here: it loads the shared `envoy.json` shape — NATS URLs, the Dispatch server URL and token — that `natstail`, the Dispatch server and the Envoy plugin all read.
