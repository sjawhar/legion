The schema every other package reads and writes through: ordered migrations applied in one transaction each at boot, the pool, and the session and people rows — which is why it imports `auth`. `internal/pgmigrate` holds the runner's rules, which the secrets broker's runner shares: the whole migration set is refused before anything applies when two files share a version or a file is misnamed or unreadable, and every migration's lock waits are bounded at five seconds. `internal/pgmigrate` reads migration and census SQL as Postgres 18's lexer does.

The schema also announces the changes the background loops wake on: `embeddings_enqueue` notifies `dispatch_embeddings` when it writes a row (0151), a row trigger on `refs` notifies `dispatch_excerpts_owed` for each document mention left owed an excerpt (0153), `delivery_settings_changed` notifies `dispatch_delivery_settings` for a settings change other than freshness (0156), a row trigger on `document_edit_notices` notifies `dispatch_edit_notices` for each notice given a due time (0157), and every event commit notifies `dispatch_events` (0107). The loops' own state is three additions: `reference_excerpt_backoff` (0152), each failing document's version, failures in a row and next attempt; `suggestion_outcome_cursor` (0154), the one row holding the highest event id the outcome sweep has judged by; and `write_suggestions.swept` (0155), whether a pass has judged a suggestion against all its events, with the partial indexes `write_suggestions_unswept` and `write_suggestions_pending_artifact`. The pool's listener pool dials the held LISTEN connections, the background loops' shared wake listener among them.

The store also holds what the related-item check reads and writes: each project's term statistics (`search_term_stats`, `search_term_totals`, rebuilt under the `search-term-stats` lease), one `related_checks` row per check, and the trigger that embeds an issue as its title and spec (migrations 0139 and 0140). The lease pool has one connection per leased loop and per caller of a delivery intake's hold, seventeen.
