### Changed
- A secrets-broker request that names no `--ttl` and asks for a human-tier secret now gets a 15-minute grant (`requests.DefaultHumanGrantLifetime`) instead of 12 hours, so the window in which the broker releases and reuses that credential is about the action the approver's card named, and a request after it waits for a person again. A signed `--ttl` is unchanged, `max-grant` still bounds it, a secret tagged `default-grant=session` still opts out, and an agent-tier request still defaults to 12 hours.
