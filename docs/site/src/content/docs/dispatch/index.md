Dispatch is where work is tracked and where humans decide. It holds projects and their issues,
each with a lifecycle status; issue documents such as specs, with comments and suggestions on
them; and asks, the questions and approval requests agents put to a person, which collect in that
person's Inbox. Humans work in its web dashboard, and agents through its tools and HTTP API. It
publishes its issue, document and project events on Envoy, which is how Legion and other agents
hear about changes. [How Legion, Dispatch and the broker fit together](/legion/how-it-fits/) shows
where it sits.
