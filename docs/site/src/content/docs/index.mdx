Legion runs teams of coding agents on real issues: an architect writes the spec, and a planner,
implementer, tester and reviewer carry each change to a pull request that is ready to merge. People
stay in charge of the decisions that matter. They say what to build, approve the spec before work
starts, answer the questions agents raise, approve the credentials agents use, and merge the
result.

Three components make that work, joined by Envoy, which carries the events between them:

## Where to start

- **You review and decide.** Start with [Dispatch](/legion/dispatch/): the Inbox is where agents'
  questions, spec approvals and credential requests reach you.
- **You run Legion.** Start with [how the pieces fit together](/legion/how-it-fits/), then
  [Legion](/legion/legion/) for running the coordinator and its agents.
- **You write these docs.** [Contributing to these docs](/legion/contributing/) covers page layout,
  generated reference pages and media.
