# The broker walkthrough's sources

Everything `../walkthrough.mp4` is built from, and how to build it again.

| Path | What it is |
| --- | --- |
| `raw/` | The footage, one file per section: four asciinema casts of the agent machine's terminal and three Playwright recordings of Dispatch, with `sections.json`, each section's wall-clock length and how closely each browser section's last frames match its result. |
| `edl.py` | The cut: which window of which file plays, in what order, and the narration parts laid over each clip at their offsets. |
| `narration/` | One MP3 per narration part, generated by `narrate.py`. |
| `narrate.py` | Generates `narration/` through ElevenLabs. The voice and its settings are its constants. |
| `build.py` | Checks the footage and the cut, renders each clip and concatenates them into `../walkthrough.mp4`. |

## Rebuild the video

Needs `agg` (`cargo install --git https://github.com/asciinema/agg`), `ffmpeg` and `ffprobe`.

```bash
cd docs/site/public/media/broker/walkthrough.src
python3 build.py --check   # the footage's capture rates, every window inside its file, every narration part inside its clip
python3 build.py           # writes ../walkthrough.mp4; renders the casts once, into build/
```

`build.py` refuses footage whose length is off its section's wall clock (a browser recording
shorter than its actions or longer than its page's life, by more than 5%; a cast more than 1.5 s
shorter than its section, or longer), a window outside its file, and a narration part that
overlaps the next or runs past its clip's end. Nothing is stretched or held: a clip is its window
of the file, at its own speed, and the audio is padded with silence, never the video with frames.

## Change the narration

Edit the text in `edl.py`, then regenerate the parts you changed (or all of them) and rebuild:

```bash
secrets ELEVENLABS_API_KEY -- uv run --no-project --with elevenlabs python3 narrate.py [PART...]
python3 build.py
```

Write a part to the clip as cut: say only what the clip shows, and keep it inside the clip's length
(`build.py --check` names a part that overruns).

## Record the footage again

`bash docs/site/media/broker/walkthrough.sh` records every section into `raw/` against the demo
rig (`docs/site/media/broker/README.md`). The sections depend on each other (the machine login
issues the session's credential, the request is the one approved), so a take records all of them.
A new take moves every window in `edl.py`: find each clip's start and end in the new files, then
re-time the narration offsets.
